TARS Servo Calibration — PySide6/QML
=====================================

The QML servo tester is responsive and supports both real Raspberry Pi servo
hardware and a safe desktop/mock mode.

Run on Raspberry Pi
-------------------

From the repository root, with the project's virtual environment active:

    python src/app-servotester-qml.py --fullscreen

On a Raspberry Pi, the app automatically connects to the PCA9685 through the
existing modules.module_servoctl code. Press ENABLE PWM only after physically
supporting TARS. Dragging a calibration slider continuously previews its offset
on the corresponding physical servo. Slider changes remain temporary until
SAVE is pressed; Save writes the ten offset values to the active config.ini.
A copy of the previous file is kept as config.calibration-backup.ini.

Calibration and range testing
-----------------------------

CALIBRATION changes the ten offsets consumed by the main TARS application.
Each slider's limits are calculated from that servo's configured endpoints, so
an offset cannot push either endpoint outside the accepted 10–600 PWM range.

RANGE TEST is deliberately separate from calibration. Select and arm one joint,
then move it from 0% to 100% of its currently calibrated endpoint range. Motion
is rate-limited, only one joint is commanded, and range tests never alter or
save an offset. Disarm the range test before supporting or repositioning TARS.

Use this mode when you want to inspect the UI without moving hardware:

    python src/app-servotester-qml.py --fullscreen --mock

Run on Windows
--------------

Double-click run-servotester-demo.bat, or run:

    python -m pip install -r requirements-servotester-qml.txt
    python src/app-servotester-qml.py

Non-Raspberry Pi computers automatically use mock mode. Use --hardware only
when deliberately testing a compatible PCA9685 environment.

Safety and controls
-------------------

- Offset changes are rejected if either configured servo endpoint would leave
  the existing safe pulse range of 10–600.
- Slider events are coalesced and PWM writes run on a serialized worker, keeping
  touch and VNC dragging responsive without competing with movement routines.
- DISABLE PWM first cancels active movement, then removes PWM from every channel
  under the shared movement lock.
- Closing the tester also disables all servo channels.
- REVERT restores the last saved offsets and previews those positions.
- NEUTRAL runs the project's existing neutral-position routine without
  changing saved calibration offsets.
- If an I2C write fails, the tester attempts to reconnect but deliberately
  leaves PWM off. Support TARS and press ENABLE PWM again to apply the complete
  calibrated pose safely.
- Closing with unsaved offsets asks whether to save, discard, or cancel.
- Escape closes the fullscreen window.

Architecture
------------

- src/app-servotester-qml.py owns configuration, state, safe hardware calls,
  mock fallback behavior, and the Qt-facing properties/signals/slots.
- src/qml/ServoCalibration.qml composes and responsively scales the dashboard.
- src/qml/CalibrationSide.qml creates the mirrored physical-side panels.
- src/qml/ServoControl.qml, Panel.qml, and TacticalButton.qml are reusable
  visual components.
